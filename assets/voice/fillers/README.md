# Междометия ожидания

Готовые WAV для встроенного дела «Дождь над Тенью»: по одному файлу на каждую стандартную фразу и каждый голос персонажей.

**Фразы:** «Хм…», «Ну…», «Секунду…»  
Файлы: `hm.wav`, `nu.wav`, `sekundu.wav`.

**Голоса:** Kore, Charon, Aoede, Fenrir, Leda, Orus  
Каталоги — в нижнем регистре ASCII: `kore/`, `charon/`, `aoede/`, `fenrir/`, `leda/`, `orus/`.

**Формат:** 24 кГц, моно, PCM s16 — тот же выход, что играет игровой путь Gemini TTS. Стиль пустой.

**Модель:** `gemini-3.8-flash-lite-tts` (первая в обычном списке моделей озвучки игры). Все 18 файлов сгенерированы этой моделью 25 ноября 2026 (Europe/Moscow).

Ключи API в репозиторий, в этот файл и в имена файлов не записываются. Для этих голосов повторная генерация на устройстве не нужна.
