# Правила для агентов

Краткий договор для правок в этом репозитории. Подробности — в `docs/ARCHITECTURE.md`, `docs/LLM_PROTOCOL.md` и `docs/BUILD.md`. Планы работ — в `docs/plans/`.

## О проекте

Detective — детективная игра-допрос на Godot 4.7 (CI и локальные тесты — Godot 4.7.2), GDScript. Персонажей играет Gemini, но что можно рассказать, решает код, не модель.

Поставка — Android (планшет, только arm64-v8a). В `export_presets.cfg` сохранён пресет `Windows Desktop`, но workflow его не экспортирует. Другие платформы не добавляйте без явной просьбы. Поле ввода `PromptField` и ввод с клавиатуры оставляйте: голос их не заменяет.

## Тесты и CI

Сначала импорт ресурсов, затем раннер:

```
godot --headless --path . --import
godot --headless --path . -s res://tests/run_tests.gd
```

Не меняйте тесты, чтобы они стали зелёными: чините код или уточняйте задачу. Перед pull request тесты должны проходить локально.

CI называется «Сборка Android» (`.github/workflows/build.yml`): тесты, затем APK. Агент сам CI не запускает — ни через `workflow_dispatch`, ни пушем «чтобы прогнать сборку». Workflow сам стартует на pull request и на пуш в `main`.

Проверка дела: `python3 tools/validate_case.py cases/<дело>.json`.

## Архитектура хода

Код решает, модель выбирает. На каждый ход `TurnOptions.build` собирает закрытый список вариантов. В JSON-ответе первым идёт поле `chosen` — номера из этого списка. `TurnOptions.plan` применяет выбор, `RulesEngine` меняет состояние.

Реплика проходит `ResponseValidator` (формат и фильтр утечек) до показа на экране и до озвучки. `Game` отдаёт сигнал `agent_replied` только после успешной проверки. Сырой ответ модели не показывайте и не озвучивайте.

Зависимости: `src/core` не знает о `dialogue`, `llm` и `ui`. UI обращается к игре через автозагрузку `Game`, не к движку правил напрямую.

## Ключи и секреты

Ключ Gemini и прочие секреты не попадают в git, логи, сохранения и сборки. Их нельзя печатать, писать в `print` / `echo` и оставлять в сообщениях коммита или pull request.

Откуда игра берёт ключ (по порядку): `user://config.cfg`, переменная окружения `GEMINI_API_KEY`, в отладочной сборке — `res://config/dev.cfg`. Пример без ключа — `config/config.example.cfg`. В `.gitignore`: `config/dev.cfg`, `*.keystore`, `*.jks`, `.env`, `export_credentials.cfg`.

В логах тела ошибок проходят `_redact`. `SaveState._without_secrets` вычищает поля `api_key`, `gemini_api_key`, `chirp_key`, `private_key`. CI и `tools/check_build.py` проверяют, что в APK нет ключа и `dev.cfg`. Ключи не ротируйте и не подменяйте «запасным» при ошибке.

## Распознавание речи (STT)

`GeminiStt`: модель зашита как `gemini-3.5-flash-lite` (модель диалога по умолчанию, `LLMConfig.DEFAULT_DIALOGUE_MODEL`), ключ — тот же, что у диалога (`LLMConfig.load_settings().api_key`). При запросе модель STT не переключается и не следует за сменой модели диалога в настройках.

На вход — WAV, моно, 16-bit, 16 кГц (`VoiceAudio`). Передискретизация линейная, без фильтра. Системное распознавание не используйте: сохранённое `mic/stt=system` при загрузке сбрасывается на `gemini`.

Thinking для STT начинается с `MINIMAL`. Если модель его отклоняет — сначала `LOW`, затем текущий код может убрать `thinkingConfig` (`off`).

По плану 9.28 (ещё не в коде): при `offline` / `timeout` у диалога и STT — два тихих повтора той же модели (паузы 1 с и 3 с), затем «Нет связи» и «Повторить»; вопрос остаётся в поле ввода, ход не применяется. Сейчас `offline` сразу даёт ошибку, без повтора; `timeout` уже может повториться, но не с этими паузами.

## Озвучка (TTS)

При сбое Gemini TTS системный голос сам не включается. Движок `system` остаётся только выбором игрока в настройках (сейчас это значение по умолчанию).

Реплику не обрезайте: в очередь и на синтез уходит полный текст после `SpeechText.clean` (очистка разметки, не усечение).

Цепочка при суточной квоте (429 `per_day` или длинный `retryDelay`), если включён `tts_auto`: `gemini-3.8-flash-lite-tts` → `gemini-3.8-flash-tts` → `chirp-3-hd`. Вверх по списку не поднимайтесь. При минутном 429 (`rate_limited`) и перегрузке (502/503/504) повторяйте ту же модель (до 3 попыток), список не спускайте. Сетевая ошибка (`offline`) список не спускает: сейчас код ту же модель сам не повторяет; по плану 9.28 повтор озвучки — по кнопке «Повторить», текст реплики на экране остаётся, строку не обрезать. Ключи не ротируйте.

## Thinking диалога

По умолчанию `thinkingLevel=MINIMAL` (`LLMConfig.DEFAULT_THINKING`). В настройках допустимы только `MINIMAL` и `LOW`. Если модель отклоняет `MINIMAL`, для неё запоминается `LOW`. Если отклоняет и `LOW` (или `thinkingLevel` не поддерживается), текущий код убирает `thinkingConfig` (`off`) и запоминает это. У запросов probe/ping thinking не ставится.

## Как работать

- Планы и заметки по крупным задачам храните в `docs/plans/` в этом репозитории.
- Коммиты делайте небольшими и по одной теме.
- Не коммитьте ключи, `config/dev.cfg`, keystore, APK и каталоги `.godot/`, `builds/`, `android/`.
- `docs/` и `tools/` в пакет не входят (`.gdignore` и `exclude_filter` пресета).
