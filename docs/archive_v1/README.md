# Архив: документы первой версии (устарели)

Эти файлы описывают **первую версию** игры и больше не актуальны. Не опирайтесь на них при реализации.

Они ссылаются на старый диздок и старые механики (автоматический поиск противоречий, давление, усталость), которых в v2 нет, и не знают про слои и замки, свидетельские показания и ручную сборку несостыковок.

Актуальные документы лежат в `docs/`:
- `DESIGN_DOC_V2.md` — дизайн-документ игры;
- документы технического диздока v2 (с суффиксом `_V2`).

Файлы оставлены только для истории.
