# Сборка

Игра собирается в GitHub Actions. Подпись Android берётся из секретов репозитория и в git не попадает. Пока секретов нет, задача подписывает пакет одноразовым ключом: такой APK не встанет поверх уже установленной игры. `version/code` равен номеру запуска GitHub Actions, имя пакета остаётся `com.o5wtf.detective`. Ключ Gemini, `config/dev.cfg` и `user://` в пакет не входят.

## Скачать готовую сборку

1. Откройте вкладку Actions репозитория и workflow «Сборка Android».
2. Выберите зелёный запуск (после слияния в `main` или ручной запуск).
3. Внизу страницы, в Artifacts, скачайте `detective-builds`.
4. Внутри архива только `Detective.apk`.

Ручной запуск: Actions → «Сборка Android» → Run workflow.

Если поставлен тег `v*`, тот же APK появляется в Releases. Пресет `Windows Desktop` в `export_presets.cfg` сохранён, но текущий workflow его не собирает.

## Планшет Android

1. Скачайте `Detective.apk` на планшет.
2. Разрешите установку из неизвестных источников для браузера или файлового менеджера, которым открываете apk.
3. Откройте apk и подтвердите установку. Если телефон пишет, что пакет конфликтует, один раз удалите старую игру: у неё другой ключ подписи. Следующие сборки с тем же секретом ставятся поверх. Архитектура — только arm64-v8a. Ориентация экрана — сенсор, альбом и портрет.
4. Запустите «Детектив».

## Локальное распознавание

В APK для arm64-v8a добавляются `libsherpa-onnx-jni.so` и `libonnxruntime.so` из официального `sherpa-onnx-2.0.3.aar` (проверка SHA-256 в `tools/fetch_sherpa_android.py`). Установленный APK из‑за них больше примерно на 27 МБ (106,65 МБ против 78,65 МБ до библиотеки): .so лежат в пакете без сжатия. Около 10 МБ — это только их сжатый архив, не размер APK. Веса модели Parakeet в пакет не входят: их игра качает сама. Перед локальным экспортом Android нужна та же команда, что выполняет CI: `python3 tools/fetch_sherpa_android.py`.

## Windows

Пресет `Windows Desktop` остаётся в репозитории. CI его сейчас не экспортирует: сборка — тесты и Android APK. Локальный экспорт тем же пресетом можно вернуть отдельно.

## Ключ Gemini

1. В игре откройте «Настройки».
2. Вставьте ключ в поле «Ключ Gemini API». Он хранится только в `user://config.cfg` на устройстве.
3. Нажмите «Проверить связь». Должно появиться «Связь есть.» Ключ на экран и в журнал не выводится.
4. «Сохранить», затем «Новое дело».

Без ключа живой допрос не стартует. Переключатель «Офлайн-отладка» обходится без сети и без ключа.

## Что не попадает в пакет

`cases/*.json` входит. Не входят `config/` (включая `dev.cfg`), `docs/`, `tools/`, `tests/`, `.github/` и файлы `*.md`.

## Локально

Нужны Godot 4.7.2, шаблоны экспорта той же версии, JDK 17 и Android SDK с `platform-tools` и `build-tools`. Пути JDK и SDK прописываются в редакторе: Export → Android. Keystore для отладки создайте сами и не коммитьте. Пресеты: `export_presets.cfg`, имена `Android` и `Windows Desktop`.
